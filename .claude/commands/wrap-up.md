오늘 세션의 작업을 마무리한다.

1. git status/diff로 현재 변경 상태 확인
2. HANDOVER.md에 다음 내용으로 인수인계 작성:
   - 완료된 작업
   - 현재 상태 (동작 여부, 중단된 지점)
   - 다음 우선순위 작업 목록
   - 실패했던 접근과 이유 (반복 방지용)
   - 확인 필요한 열린 질문
3. 커밋되지 않은 변경이 있으면 커밋할지 물어봐
4. PROGRESS.md가 있으면 오늘 항목 추가

---

## 이 저장소 주의사항

- **git 저장소다** (2026-08-15 `git init`, 브랜치 `main`, 원격 없음). 1·3번은 그대로 수행한다.
  단 `~/.gitignore_global`이 `.gitignore` 자체를 무시하므로 이 저장소의 `.gitignore`는 status에 잡히지 않는다 — 누락으로 오해하지 말 것.
- `PROGRESS.md`는 존재한다. 4번에서 새 파일을 만들지 말고 기존 문서의 구조(1. 현재 상태 / 3. 미완료 작업 / 4. 알려진 이슈 / 6. 다음 세션 제안 순서)에 맞춰 갱신하고, 상단 **최종 갱신** 날짜도 함께 고친다.
- 날짜는 `date +%Y-%m-%d`로 확인해 절대 날짜로 적는다 ("어제", "지난주" 금지).
- `HANDOVER.md`가 이미 있으면 통째로 덮어쓰지 말고 오늘 세션 섹션을 **맨 위에 추가**한다.
- 문서는 한국어로 쓴다 (이 프로젝트 문서 관례).
